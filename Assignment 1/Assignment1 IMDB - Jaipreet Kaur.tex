\subsection{Purpose (fast version)}\label{purpose-fast-version}

This notebook \textbf{runs faster} by doing a focused set of experiments
that still addresses every assignment requirement:

\begin{enumerate}
\def\labelenumi{\arabic{enumi})}
\tightlist
\item
  \textbf{Hidden layers:} compare 1 vs 2 (baseline) vs 3\\
\item
  \textbf{Hidden units:} compare 32 vs 64 (baseline) vs 128\\
\item
  \textbf{Loss:} compare \texttt{mse} vs \texttt{binary\_crossentropy}\\
\item
  \textbf{Activation:} compare \texttt{tanh} vs \texttt{relu}\\
\item
  \textbf{Technique:} compare baseline vs \textbf{Dropout + L2 + Early
  stopping}
\end{enumerate}

Instead of a full grid, we use a \textbf{one-factor-at-a-time}
experiment plan (about 8 model runs total).

\subsubsection{Conclusion}\label{conclusion}

\begin{itemize}
\tightlist
\item
  Changing the number of hidden layers (1 vs 3) shows how model capacity
  affects \textbf{validation and test accuracy}.
\item
  Changing hidden units (32/64/128) shows how increasing capacity can
  help until overfitting begins.
\item
  Using \textbf{MSE} instead of \textbf{binary cross-entropy} typically
  reduces classification performance, since cross-entropy is designed
  for probabilistic binary classification.
\item
  Using \textbf{tanh} instead of \textbf{relu} changes learning
  dynamics; performance may differ due to saturation vs piecewise-linear
  behavior.
\item
  The technique (\textbf{Dropout + L2 + early stopping}) is used to
  \textbf{improve validation accuracy} by reducing overfitting.
\end{itemize}

The final selected model is the experiment with the highest validation
accuracy (and strong test accuracy), shown in the \texttt{best} row.
